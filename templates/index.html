How the Detection Pipeline Works

Every image goes through a strict multi-layer verification and inference pipeline.

1
📁

Client-Side Capture

The browser accepts a photo via file picker or drag-and-drop. Size is checked against the 5MB limit and an immediate local preview is rendered via URL.createObjectURL().

2
🛡️

Flask & Pillow Validation

The backend verifies extension, rejects empty payloads, and uses Pillow's image.verify() to guarantee file integrity before resizing to 224×224 pixels.

3
🧠

MobileNetV2 Inference

The preprocessed tensor runs through the ONNX Runtime graph on CPU. Real logits are transformed into true softmax probabilities across all 38 agricultural classes.

4
📋

Care Recommendations

The winning class is mapped to our scientific agricultural knowledge base to return symptoms, immediate interventions, and preventative management.

Technical Architecture & Interview Reference

Key implementation decisions designed for clarity, safety, and production readiness.

Backend Architecture

  • Framework: Python Flask 3.1
  • Routing: RESTful API pattern (POST /api/predict, GET /api/status).
  • Validation: MIME type checking, extension whitelist, and 5MB payload limit enforcement.
  • Memory-Safe: Processes image streams directly in memory without unmanaged disk writes.

Image Processing (Pillow)

  • Integrity: Calls Image.verify() to catch corrupted or malicious payloads.
  • Aspect-Ratio Preserving: Scales shortest dimension to 256px before center-cropping to 224×224.
  • Tensor Formatting: Normalizes RGB pixels to [-1.0, 1.0] and transposes to (1, 3, 224, 224).

AI Classification Model

  • Model: MobileNetV2 fine-tuned on PlantVillage benchmark dataset.
  • Format: ONNX (Open Neural Network Exchange), running via onnxruntime.
  • Integrity: Zero fabricated predictions; calculates mathematical softmax across all 38 classes.
  • Graceful Fallback: Clearly marks AI as offline if weights are absent rather than faking outputs.
